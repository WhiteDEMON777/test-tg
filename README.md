# Telegram GREEN-API Chat

Минимальный React-чат для отправки и получения текстовых сообщений в Telegram через GREEN-API.

## Требования

- Node.js 20 или новее
- npm
- Аккаунт и инстанс GREEN-API для Telegram

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте адрес из терминала, обычно:

```text
http://127.0.0.1:5173/
```

## Сборка проекта

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.

## Как пользоваться

1. Введите данные GREEN-API:
   - `idInstance`
   - `apiTokenInstance`
   - `API URL`, если он отличается от `https://api.green-api.com`
2. Введите номер телефона получателя или готовый `chatId`.
3. Нажмите `Создать чат`.
4. Нажмите `Включить получение`, чтобы приложение начало получать входящие уведомления.
5. Напишите текстовое сообщение и отправьте его.
6. Ответ получателя появится в окне чата после получения уведомления от GREEN-API.

## Используемые методы GREEN-API

- Отправка сообщений: `sendMessage`
- Получение сообщений: `receiveNotification`
- Удаление обработанного уведомления: `deleteNotification`
